Scope: `docs/l02-pid-control/index.md` and `slides/l02-pid-control/index.md`,
against PEDAGOGY.md as first recorded (`6dbf514`).

Lecture 2 was written before the principles existed, to a different brief: a
50-minute lecture with a separate hour-long example sheet. Most findings follow
from that. The largest gaps are structural (P8) and in ordering (P2); after those,
depth management (P4) and reachable figure code (P6).

## Not findings, but noted

- Every result is tied to both the Bode plot and the step response. That is A2 done well, and worth keeping as a pattern.
- The plant's simplification is stated honestly in `#pitch-loop`, which is P5 working as intended.
- The code is run, checked and in both languages, which already satisfies most of P7.

## Questions this review raises about the principles

- **R1. The aside convention.** P4 needs a single, recognisable form for depth: a collapsible block with a fixed title such as "Going further", or a tiered set such as "Why this works" and "Extension". It should print expanded, which the print styles already handle.
- **R2. P1 and P2 both want the opening.** A section can't open with the design cycle and with a concrete example at once. A workable order might be the cycle at lecture level, and the example at section level.
- **R3. P6 and P7 need a visible distinction.** Students should tell at a glance whether code is theirs to run or shows how a figure was made. That wants a convention, and possibly styling.
