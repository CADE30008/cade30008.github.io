# Content status

What actually exists, as opposed to what the navigation implies. Kept current
because the site looks complete and is not: a visitor sees eleven weeks with
handouts, decks, example sheets and solutions, and all but one are scaffolds.

Update this in the same change as the content it describes.

## Status values

| Value | Means |
|---|---|
| **placeholder** | Generated by `npm run new:lesson`. Structure only. Topic is a guess and carries no commitment |
| **scoped** | Topic, design question, case and cliffhanger agreed. Nothing written |
| **drafted** | Handout written; deck, example sheet and solutions may lag |
| **reviewed** | Been through a principles review (PEDAGOGY.md), findings recorded in `reviews/` |
| **taught** | Delivered, and the run sheet updated with real timings |
