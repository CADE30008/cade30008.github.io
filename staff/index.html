Anything linked from here can be opened by anyone with the address. That is fine for run sheets and code, and it is not fine for assessment material, marks, or anything with a student's name on it. Those live in private/ in the repository and are never committed.

Getting the files

The staff test kit is in OneDrive, under Teaching › CADE30008 Flight Dynamics and Advanced Control › 2026-27 › staff-kit. It used to be a public MATLAB Drive share so it could be fetched at the bench without a MATLAB Drive login; OneDrive already reaches the laboratory machine, so the share was paying for a problem nobody had.

If you need it and don't have that folder, two other routes, neither needing anything from me:

  • Everything is in the public repository, CADE30008/cade30008.github.io. The kit's own files are in drive/staff/, and the parts students also run are in docs/laboratory/code/. Clone it, or use GitHub's Download ZIP, and you have the lot.
  • The student files are on the link above, which needs no sign-in.

Ask me for access to the OneDrive folder if you would rather have it syncing than fetch it each time.

Nothing with a student's name on it, and nothing about assessment, is in any of these. That material is in a private repository and is never in this one.

Check these annually. A new cohort folder means a new share id, and a stale share link is dead rather than wrong, so nothing in the build will notice. See teaching/annual-update.md.
