# For AI assistants working in this repository

**Read [AGENTS.md](AGENTS.md) before writing or editing anything.** It is the
authoring contract: what lives where, how weeks are structured, how slides and
handouts are kept in sync, and how to write.

Three things in it that are most often ignored, so they are repeated here.

**Prose must not read as machine-written.** See "Prose that doesn't read as
machine-written" in AGENTS.md. In short: em dashes stand in for punctuation you
should have chosen; never say a thing and then explain that it matters; drop
*genuinely*, *worth knowing*, *which is exactly why*, *that is the whole point*,
*lands*, *buys you*, *does the heavy lifting*. Read it aloud before you keep it.

**Check, don't assert.** Every number traces to a script, every figure to the
code that drew it. If you cannot verify a claim, say so rather than phrasing it
confidently. Run the build and read the output.

**Student-facing material is evergreen.** No week numbers, no references to
another unit's notes, no "the textbook". Students arrive from several
programmes and the site outlives the cohort.

Run `npm run check` and `npm run curriculum` before you finish.
