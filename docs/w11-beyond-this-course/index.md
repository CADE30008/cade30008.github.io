    By the end of this week you should be able to:

    - describe where gain scheduling, adaptive, model predictive, robust and learning-based control are used in aerospace, and the problem each addresses;
    - explain why adaptive and learned controllers are hard to certify, using the X-15 accident as an example;
    - identify which of this unit's methods the advanced control unit builds on.
