!!! abstract "Learning outcomes"
    By the end of this week you should be able to:

    - describe the layers of an aircraft's flight control system — stability augmentation, control augmentation, autopilot and modes — and the job of each;
    - design an inner–outer loop structure, and justify the separation in bandwidth between the loops;
    - explain how handling-qualities requirements shape a flight control system;
    - analyse how sensing, control authority and mode logic contributed to a real accident, and the design principle each illustrates.
