*[BIBO]: bounded input, bounded output: a bounded input never produces an unbounded output
*[CAA]: Civil Aviation Authority
*[DoF]: degree of freedom: one independent way a system can move
*[EASA]: European Union Aviation Safety Agency
*[FAA]: Federal Aviation Administration
*[ILO]: intended learning outcome, from the unit catalogue
*[LQR]: linear quadratic regulator: state feedback that minimises a weighted sum of state error and control effort
*[LTI]: linear time-invariant: the class of system this course's tools apply to
*[MBD]: model-based design: one set of models carried from requirements through to implementation
*[MIMO]: multiple input, multiple output
*[PI]: proportional–integral control: PID without the derivative term
*[PID]: proportional–integral–derivative: the three-term controller, and the most used in engineering
*[PIO]: pilot-induced oscillation: an oscillation sustained by the pilot's own corrections
*[RHP]: right half-plane: where a pole means instability, and a zero means an initial response the wrong way
*[SAS]: stability augmentation system: feedback that improves an aircraft's natural behaviour
*[SISO]: single input, single output
*[system ID]: system identification: getting a model from measured data rather than from physics
*[ZOH]: zero-order hold: holding a sampled value constant until the next sample
*[trim]: a steady condition the aircraft holds, with the forces balanced
*[plant]: the thing being controlled, and everything outside the controller
*[saturation]: an actuator reaching its limit and unable to give more
*[rate limit]: a limit on how fast an actuator can move, as distinct from how far
*[damping ratio]: how quickly an oscillation dies away: 0 rings forever, 1 does not oscillate
*[natural frequency]: how fast an oscillatory system wants to move
*[short period]: the fast longitudinal pitching oscillation
*[phugoid]: the slow longitudinal exchange of speed and altitude
*[Dutch roll]: the lateral-directional oscillation coupling yaw and roll
*[spiral mode]: the slow lateral divergence or convergence in bank
*[roll subsidence]: the rapid damping of roll rate
*[handling qualities]: how an aircraft behaves to the pilot flying it, against published standards
*[observer]: something that reconstructs unmeasured states from measured ones
*[controllability]: whether the inputs can move every state
*[observability]: whether the outputs reveal every state
