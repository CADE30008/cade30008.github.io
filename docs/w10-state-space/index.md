<!-- outcomes:start -->
!!! abstract "Learning outcomes"
    By the end of this week you should be able to:

    - write a state-space model of a small multi-state system, and relate it to the transfer function;
    - explain what a state is, and what feedback from every state can do that output feedback cannot;
    - design a state-feedback controller by pole placement, for a system whose states are all measured;
    - use LQR as a tuning method, and explain the trade its weights express.
