# Private material

Everything in this folder except this file is ignored by git, so it is never
committed or published.

Put here anything that must not appear in a public copy of the course:

- `assessment/`: briefs, rubrics, marking schemes, model answers, per-student
  parameters, last year's assignment and exemplars, and University guidance.
- `quanser/`: Quanser manuals, models and other licensed resources.

Any format is fine: PDF, Word, PowerPoint, Excel, Markdown, MATLAB and Simulink
files. Keep the original files; converted copies for reading can sit alongside.
